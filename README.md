# POS ร้านคุณชายน้อย (เวอร์ชัน 3)

Google Sheets = ฐานข้อมูล · Apps Script = API · GitHub = เก็บซอร์สโค้ด · Netlify = หน้าเว็บ (คอม + มือถือ)

## สิ่งที่เพิ่มในเวอร์ชัน 3

- FIFO จริง: สินค้า/รหัสเดียวกันที่รับเข้าต่างราคาจะเป็นคนละ lot และเมื่อตัดขาย ระบบตัด lot ที่รับเข้าก่อน พร้อมบันทึกต้นทุนที่ตัดจริง ไม่มีการใช้ทุนเฉลี่ยกับล็อตใหม่
- เปิดดูและแก้ไขบิลซื้อได้จากปุ่ม “เปิด/แก้ไข” ตราบใดที่ล็อตนั้นยังไม่เคยถูกขาย เพื่อปกป้องประวัติต้นทุน
- เงินสดเปิด/ปิดกะแยกจำนวน 1, 2, 5, 10, 20, 50, 100, 500 และ 1,000 บาท แล้วรวมให้อัตโนมัติ
- เมื่อส่งบิลขายไม่ได้เพราะขาดการเชื่อมต่อ บิลจะพักใน local storage ของอุปกรณ์และส่งอัตโนมัติเมื่อออนไลน์ (อย่าล้างข้อมูลเว็บก่อนส่งสำเร็จ)
- ใบลดหนี้และคืนสินค้า: แอดมินทำได้จากเมนูลูกหนี้/เจ้าหนี้; คืนสินค้าจะเพิ่มสต็อกกลับด้วยต้นทุนเดิม
- เมนูค่าใช้จ่ายบริหาร พร้อมบันทึกวิธีชำระและสมุดเงินสด
- `setupAll()` จะรวม Spreadsheet และทุกไฟล์ที่ระบบสร้างไว้ในโฟลเดอร์ Google Drive `POS - ร้านคุณชายน้อย` เดียวกัน
- หน้าลูกหนี้/เจ้าหนี้มีประวัติรับและจ่ายชำระ แยกวันเวลา เลขที่เอกสาร ยอด วิธีชำระ ยอดคงเหลือหลังรายการ และสลิป

## อัปเดตจากเวอร์ชันเดิม (ทำตามลำดับ)

### 1. Apps Script
1. เปิด Google Sheet "POS-ร้านคุณชายน้อย" > ส่วนขยาย > Apps Script
2. เปิดทีละไฟล์ (Code, Parties, Products, Purchases, Reports, Sales, Setup, StockCash, Users, Util)
   ลบโค้ดเดิมทั้งหมด (Ctrl+A แล้ว Delete) แล้ววางโค้ดจากไฟล์ .gs ชื่อเดียวกันในโฟลเดอร์ `apps-script/`
3. กด Ctrl+S บันทึก
4. เลือกฟังก์ชัน `setupAll` > เรียกใช้ (รันซ้ำได้ ข้อมูลเดิมไม่หาย)
5. เลือกฟังก์ชัน `testReceiptPdf` > เรียกใช้ > ถ้าขอสิทธิ์ให้กดอนุญาต
   ดูบันทึกการดำเนินการ จะมีลิงก์ใบเสร็จทดสอบ (ลบไฟล์ทดสอบทิ้งได้)
6. **Deploy เวอร์ชันใหม่ (สำคัญที่สุด)**: การทำให้ใช้งานได้ > จัดการการทำให้ใช้งานได้ > ไอคอนดินสอ >
   เวอร์ชัน: **เวอร์ชันใหม่** > ผู้มีสิทธิ์เข้าถึง: **ทุกคน** > ทำให้ใช้งานได้ (URL เดิม ไม่ต้องแก้ config.js)
7. ทดสอบ: เปิด URL ที่ลงท้าย /exec ในเบราว์เซอร์ ต้องเห็น `{"ok":true,...}`
   ถ้าเห็นหน้าล็อกอิน Google หรือหน้า error = ตั้งสิทธิ์ผิด ให้กลับไปข้อ 6

### 2. GitHub
1. เข้า repo POS_2026 > โฟลเดอร์ public > Add file > Upload files
2. ลากไฟล์ทั้งหมดในโฟลเดอร์ `public/` ชุดใหม่ขึ้นไป (index.html, sw.js, manifest.json, โฟลเดอร์ css และ js)
   ไฟล์ `js/config.js` ในชุดนี้ใส่ URL ของคุณไว้แล้ว
3. Commit changes > Netlify อัปเดตเองใน 1 นาที
4. เปิดเว็บแล้วกด Ctrl+Shift+R (ล้างแคช) หน้าล็อกอินต้องขึ้น "● เชื่อมต่อฐานข้อมูลได้"

## ลำดับเริ่มใช้งาน
ตั้งค่า (ข้อมูลร้าน + พนักงาน) > สินค้า > สต็อก (ปรับสต็อกยอดยกมา) หรือ ซื้อ > เงินสด (เปิดกะ) > ขาย

## ที่เก็บข้อมูลและไฟล์ใน Google Drive
โฟลเดอร์ "POS - ร้านคุณชายน้อย" (โฟลเดอร์เดียว)
- ไฟล์ฐานข้อมูล Google Spreadsheet
- ใบเสร็จ PDF, สลิปโอนเงิน และไฟล์สำรองที่ระบบสร้าง

ชื่อไฟล์มีเลขเอกสาร/เวลา จึงไม่ทับกัน แม้จัดเก็บในโฟลเดอร์เดียว
